# Deefy

Application PHP permettant de créer des playlists et d’y ajouter des pistes audio.


## Fonctionnalités

- Consulter les playlists
- Créer une playlist
- Ajouter des pistes au format MP3
- Lire les pistes avec le lecteur intégré
- Formulaire d’inscription

## Technologies

PHP, MySQL, HTML, CSS et JavaScript.
